Football Skills with Wyatt

A father-and-son exploration of what football skill is, and how a Bayesian model measures it

Interactive explorer for a four-skill version of the Soccer Factor Model (Andorra & Göbel, 2024), fitted to ten seasons of Understat data from Europe’s top five leagues.

This is a fun, exploratory project that I’m doing with my son Wyatt, who is six. We want to find out (a) which parts of football skill can be measured, and (b) how the Soccer Factor Model works. It comes from Andorra & Göbel (2024), Unveiling True Talent.

The model is fitted to 593 forwards across ten seasons (2014/15–2023/24) of the Premier League, La Liga, Bundesliga, Serie A and Ligue 1. Its rankings are uncertain, and the intervals show by how much. How the model works →

function findPlayer(q, fallback) {
  if (q && byName.has(q)) return byName.get(q);
  if (q && q.trim().length >= 2) {
    const n = norm(q.trim());
    const hit = bySAR.find(p => norm(p.name).includes(n));
    if (hit) return hit;
  }
  return byName.get(fallback);
}

function poisson(lambda) {   // Knuth; fine for the small rates here
  const L = Math.exp(-lambda); let k = 0, p = 1;
  do { k++; p *= Math.random(); } while (p > L);
  return k - 1;
}
function skillSays(k, p) {
  const m = Math.exp(p.skills[k].mean), st = p.skills[k].stars;
  if (k === "shoot")  return m >= 1.05 ? `On an average team, he'd take ${m.toFixed(1)}× as many shots as a typical forward.` : m <= 0.95 ? `On an average team, he'd take fewer shots than a typical forward (${m.toFixed(1)}×).` : "On an average team, he'd take about as many shots as a typical forward.";
  if (k === "fox")    return m >= 1.05 ? `He finds better spots: on an average team his chances would be ${m.toFixed(1)}× as good as a typical forward's.` : m <= 0.95 ? `He shoots from harder places than a typical forward (${m.toFixed(1)}×).` : "His chances are about as good as a typical forward's.";

}

2. Who’s better? Play 100 pretend matches

Pick two players. The computer plays 100 pretend matches, with both players in equally good teams. Each dot is one match: a blue dot means the first player scored more, an orange dot means the second player did, and a grey dot means a tie.

race = {
  const A = raceA, B = raceB;
  const la = draws.goals90_level[A.i], lb = draws.goals90_level[B.i];

    }
    return html`<div class="fw-race">
      <div class="fw-dots" role="img" aria-label="${nA} blue, ${nB} orange, ${nT} ties">${dots}</div>
      <div class="fw-tally">
        <div class="fw-tally-row"><span class="fw-key" style="background:${COLOR_A}"></span><b>${nA}</b> ${A.name} scored more</div>
        <div class="fw-tally-row"><span class="fw-key" style="background:${COLOR_B}"></span><b>${nB}</b> ${B.name} scored more</div>
        <div class="fw-tally-row"><span class="fw-key" style="background:var(--fw-tie)"></span><b>${nT}</b> ties</div>
        <p style="margin-top:0.8rem">${done ? verdict : play === 0 ? "Press the button to play!" : "Playing…"}</p>
      </div>
    </div>`;
  };
  if (play === 0) { yield render([], false); return; }
  const res = [];
  for (let m = 0; m < 100; m++) {
    const j = Math.floor(Math.random() * la.length);   // a random posterior draw for each match
    const ga = poisson(la[j]), gb = poisson(lb[j]);
    res.push(ga > gb ? "a" : gb > ga ? "b" : "t");
  }
  for (let k = 0; k <= 100; k += 2) {
    yield render(res.slice(0, k), k === 100);
    await Promises.delay(45);
  }
}

Why are the results different every time you press the button? Because football is full of luck, and because the model isn’t 100% sure exactly how good each player is.

What is being estimated

Each forward \(p\) has four correlated skills, \(\alpha_p = (\alpha^{\text{shoot}}, \alpha^{\text{fox}}, \alpha^{\text{sniper}}, \alpha^{\text{create}}) \sim \text{MVN}(0, \Sigma)\), with an LKJ prior on the correlations. For each player-season \(r\), every skill \(k\) gets its own linear predictor:

\[\eta_{k,r} = \mu_k + \lambda_{k,\text{league}(r)} + \beta_k\,\text{TS}_r + h_k(N^S_r) + \alpha_{p(r),k}\]

Here TS is the team’s season points per game minus the league average: the paper’s team factor, whose job is to separate the player from his team. \(h_k\) is a Matérn-5/2 HSGP maturity curve over seasons observed. The likelihoods are:

Skill Data Likelihood
Shooting non-penalty shots NegBin\((\tfrac{\text{min}}{90} e^{\eta_\text{shoot}})\)
Fox npxG per shot \(\log(\text{npxG}/\text{shot}) \sim N(\eta_\text{fox}, \sigma/\sqrt{\text{shots}})\)
Sniper non-penalty goals Poisson\((\text{npxG}\, e^{\eta_\text{sniper}})\)
Creating key passes NegBin\((\tfrac{\text{min}}{90} e^{\eta_\text{create}})\)

Shots/90 × xG/shot × goals/xG = goals/90, so the first three skills multiply into expected non-penalty goals per 90. SAR is that rate with the team factor set to zero (a level field), minus the replacement pool’s rate. PAR keeps each player’s real team strength. PAR − SAR is his team lift relative to the pool’s. All intervals are 83%, as in the paper.

rlp = {
  const m = players.map(p => p.goals90_level.mean), s = [...m].sort((a, b) => a - b);
  const lo = q(s, pool.lo), hi = q(s, pool.hi);
  const inPool = players.filter((p, i) => m[i] >= lo && m[i] <= hi).map(p => p.i);

function dimDraws(key, i) {

}
